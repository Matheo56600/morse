Traducteur Morse

Encodeur et décodeur Morse réversible
Format utilisé

Chaque caractère est stocké comme :

type|codeMorse

Types :
U = majuscule
L = minuscule
D = chiffre
S = caractère spécial
E = espace
N = retour à la ligne
T = tabulation
X = caractère Unicode

Les caractères sont séparés par ;.

Exemple :
Password 123!
conserve exactement la casse, l'espace, les chiffres et le caractère !.
