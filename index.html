```html Encodeur Morse personnalisé
Encodeur Morse personnalisé

Morse avec distinction entre majuscules et minuscules
Format utilisé :
• Une lettre = son code Morse
• Une minuscule possède un _ supplémentaire à la fin
• Les lettres sont séparées par un espace
• Les mots sont séparés par /

Exemple :
AaBb devient .- .-_ -... -..._
```
