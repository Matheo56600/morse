```html Traducteur Morse
Traducteur Morse

Encodeur et décodeur Morse réversible
Informations

Le système conserve exactement :
• les majuscules
• les minuscules
• les chiffres
• les caractères spéciaux
• les espaces
• les retours à la ligne

Chaque caractère possède un identifiant permettant au décodage de reconstruire exactement le texte original.

Exemple :
Password 123!
sera décodé exactement en :
Password 123!
```
