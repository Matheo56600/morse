Traducteur Morse

Encodeur et décodeur Morse 100% réversible
Format utilisé

Chaque caractère est stocké comme :

type|codeMorse

Types :
U = majuscule
L = minuscule
D = chiffre
S = caractère spécial
E = espace
N = retour à la ligne
T = tabulation
X = caractère Unicode (point de code en hexadécimal)

Les caractères sont séparés par ;.

Exemple :
Password 123!
conserve exactement la casse, l'espace, les chiffres, la ponctuation et même les emojis ou accents non listés (grâce au repli Unicode).
